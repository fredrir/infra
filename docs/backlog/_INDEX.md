# Backlog

## Layout

| Path                                                 | Description                                                                             |
| ---------------------------------------------------- | --------------------------------------------------------------------------------------- |
| [`<task-id>.md`](./<task-id>. md)                    | Planned baclog item which doesn't belong to a spesific plan                             |
| [`<plan-id>/_INDEX.md`](./<plan-id>/INDEX.md)        | Title, short description (max 4 sentences), and an index of tasks. For a long term plan |
| [`<plan-id>/<task-id>.md`](./<plan-id>/<task-id>.md) | A task part of a plan                                                                   |
